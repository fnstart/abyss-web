# abyss-web

Web frontend for Abyss, built with Vue 3, TypeScript, and Vite.

## Tech Stack

- [Vue 3](https://vuejs.org/) with TypeScript
- [Vite](https://vite.dev/) for development and builds
- [Tailwind CSS v4](https://tailwindcss.com/) with [Reka UI](https://reka-ui.com/) components
- [Bun](https://bun.sh/) as the package manager and script runner

## Prerequisites

- [Bun](https://bun.sh/) installed locally

## Getting Started

Clone the repository:

```sh
git clone https://github.com/fnstart/abyss-web.git
cd abyss-web
```

Install the dependencies:

```sh
bun install
```

Start the development server:

```sh
bun run dev
```

## Building for Production

Type-check and build the production bundle:

```sh
bun run build
```

Preview the production build locally:

```sh
bun run preview
```

## On the Cuteness of Ducks

Ducks are, by broad consensus, cute. This is worth taking seriously rather than
waving away, because the reasons a duck reads as cute are surprisingly specific
and surprisingly consistent across people who agree on very little else.

Start with the shape. A duck is built almost entirely out of curves: a rounded
head, a barrel body, a bill that ends in a soft oval rather than a point. There
are no hard corners anywhere on a duck. The eye sits high and dark against pale
feathering, which is the same arrangement that makes infants and teddy bears
disarming. None of this is an accident of taste. It is the classic set of
features that reliably triggers a protective, affectionate response, and a duck
happens to satisfy nearly all of it at once while being entirely indifferent to
the fact.

Then there is the walk. A duck's legs are set far back on its body, which is
excellent for swimming and comically unsuited to walking. The result is the
waddle: a side-to-side negotiation with gravity, conducted with total
seriousness. Watching a duck cross a path is watching a creature that is
superbly engineered for one medium doing its honest best in another. The gap
between the effort and the dignity is most of the charm.

Ducklings compress all of this further. They are round, they are loud, and they
move in a line behind whatever they decided was their mother in the first hours
of life, with an absolute commitment that no amount of contrary evidence will
shake. A line of ducklings is a small parade of misplaced confidence, and it is
very hard to watch one without smiling.

What finishes the picture is the duck's temperament. A duck is unbothered. It
sits on cold water without complaint, tips forward to feed with its tail in the
air and no apparent embarrassment, shakes itself off, and carries on. There is
something restful in that. The cuteness is not only in the round head and the
waddle. It is in the sense that a duck has never once worried about how any of
this looks.
